# 📊 Marketing Analytics — Сквозная маркетинговая аналитика

> **Современное SPA-приложение сквозной аналитики для объединения данных Meta Ads и Bitrix24 CRM.**  
> Стек: **React 18 + Vite 5 + Tailwind CSS 3 + Recharts + Supabase + SheetJS + PapaParse**.

---

## ⚡️ Ключевые возможности

### 1. 🔗 Интеллектуальный матчинг данных (Meta Ads ↔ Bitrix24)
- **Многоуровневый алгоритм связывания сделок:**
  1. Точное совпадение по `utm_campaign`.
  2. Поиск по подстрокам в названии кампании.
  3. Умный поиск по названию CRM-формы (`formname`), теме сделки, `utm_source`, `utm_content` и семантическим маркерам.
- **Распределение агрегированных периодов Meta:** если рекламный отчет выгружен общей строкой за период (без посуточной разбивки), система автоматически и равномерно распределяет расход, клики, показы и лиды по активным дням кампании.
- **Защита от сбоев локали дат (Excel Date Self-Healing):** автоматическое исправление инверсии дней и месяцев при парсинге файлов с американской локалью (например, `12.08` как 8 декабря превращается обратно в 12 августа).

### 2. 📈 Аналитический дашборд
- **KPI-карточки верхнего уровня:** Расход ($ и ₸), Показы, Клики, CTR, CPC, Лиды Meta и CRM, Конверсии (CR), Продажи, Выручка, Чистая прибыль, CPL, CPO, ROAS и ROMI.
- **Двухосевой график «Расходы / Выручка»:** наглядное сопоставление затрат ($) и отдачи (₸) по каждой рекламной кампании.
- **Динамика по дням с переключением метрик:** просмотр трендов по Расходу, Лидам Meta, Лидам CRM, Оплатам и CPL с детальной плавающей подсказкой (Tooltip).
- **Интерактивная воронка конверсии:** от Показов и Кликов до кастомных этапов пайплайна Bitrix24.
- **Linear-Style инсайты и аномалии:** моментальное выявление лидеров окупаемости, кампаний без продаж и аномалий в конверсиях.
- **План-Факт анализ:** установка целевых бюджетов, CPL и выручки как на общий дашборд, так и на каждую отдельную кампанию с расчетом выполнения KPI.

### 3. 👁️ Управление видимостью кампаний
- Скрытие неактивных или нерелевантных кампаний в один клик по иконке глаза (`EyeOff`).
- **Сквозная синхронизация:** скрытые кампании моментально исключаются из таблицы, графиков, общих KPI и утреннего отчета.
- Быстрое восстановление скрытых кампаний через выпадающее меню панели фильтров.

### 4. 📝 Готовый утренний отчёт (Telegram / WhatsApp)
- Генерация аккуратного структурированного текста для отправки команде в один клик:
  - **За выбранный день:** распределенный расход Meta, клики, CTR, лиды, новые сделки CRM, оплаты, выручка, CPL и дневной ROAS.
  - **Сводный за весь период:** статистика по всем активным кампаниям и итоговые бизнес-показатели.
- Автоматическая фильтрация «пустышек» ($0 расхода) и исключение скрытых кампаний с индикацией в шапке окна.

### 5. 🗂 Вкладка «CRM / Bitrix24»
- Полноценный анализ базы лидов: распределение сделок по стадиям, менеджерам (ответственным), источникам и UTM-меткам.
- Таблица сделок с поиском по клиенту/номеру, фильтром по датам и суммам.

### 6. 💱 Мультивалютность и маржинальность
- Динамический ввод курса доллара (USD → KZT / RUB) с мгновенным пересчетом всех финансовых метрик.
- Настройка маржинальности бизнеса для точного расчета **ROMI** (окупаемость с учетом себестоимости).

### 7. ☁️ Облачная синхронизация (Supabase) + LocalStorage
- Авторизация пользователей (Email + пароль) и гостевой режим.
- Сохранение истории выгрузок в облачную БД с возможностью загрузить прошлый отчет в один клик.
- Сохранение индивидуального порядка стадий воронки и планов кампаний.
- Надежное резервное кэширование активной сессии в `localStorage` браузера.

### 8. 📤 Экспорт отчетов
- Выгрузка обработанной таблицы с итоговыми метриками в форматы **Excel (.xlsx)** и **CSV**.

## 📑 Формат входных данных

### 1. Meta Ads (CSV или XLSX)
Система автоматически распознает колонки по популярным названиям из Ads Manager:
| Каноническое поле | Примеры распознаваемых колонок |
|---|---|
| `campaign_name` | `Название кампании`, `Campaign name`, `Campaign` |
| `adset_name` | `Название группы объявлений`, `Ad Set Name` |
| `ad_name` | `Название объявления`, `Ad Name` |
| `date` | `Дата начала отчетности`, `Дата начала`, `Day`, `Date start` |
| `date_end` | `Окончание отчетности`, `Дата окончания`, `Date stop` |
| `spend` | `Потраченная сумма (USD)`, `Потраченная сумма`, `Spend`, `Amount spent` |
| `impressions` | `Показы`, `Impressions` |
| `clicks` | `Клики (все)`, `Клики по ссылке`, `Clicks` |
| `leads` | `Результат`, `Лиды`, `Results`, `Leads` |

### 2. Bitrix24 CRM (XLSX, XLS или CSV)
| Каноническое поле | Примеры распознаваемых колонок |
|---|---|
| `deal_id` | `ID`, `ID сделки`, `Номер` |
| `created_date` | `Дата создания`, `Дата добавления`, `Дата` |
| `deal_name` | `Название сделки`, `Тема`, `Сделка` |
| `stage` | `Стадия сделки`, `Стадия`, `Этап` |
| `amount` | `Сумма`, `Бюджет`, `Сумма сделки` |
| `utm_campaign` | `UTM Campaign`, `utm_campaign`, `Кампания` |
| `utm_source` | `UTM Source`, `Источник`, `Источник сделки` |
| `formname` | `Создана CRM-формой`, `formname`, `Название формы` |

## 🧮 Вычисляемые показатели

| Метрика | Формула расчета | Описание |
|---|---|---|
| **CTR** | `(Клики / Показы) × 100%` | Кликабельность объявлений |
| **CPC** | `Расход / Клики` | Средняя стоимость клика |
| **CPM** | `(Расход / Показы) × 1000` | Стоимость 1 000 показов |
| **CR (Meta)** | `(Лиды Meta / Клики) × 100%` | Конверсия клика в заявку Meta |
| **CR (BX)** | `(Лиды CRM / Клики) × 100%` | Конверсия клика в сделку CRM |
| **CPL** | `Расход ($) / Лиды CRM` | Реальная стоимость привлечения лида |
| **Win Rate**| `(Оплаты / Лиды CRM) × 100%` | Процент закрытия лидов в продажу |
| **CPO** | `Расход ($) / Оплаты` | Стоимость привлечения покупателя |
| **ROAS** | `((Выручка - Расход_₸) / Расход_₸) × 100%` | Окупаемость расходов на рекламу |
| **ROMI** | `((Выручка × Маржа - Расход_₸) / Расход_₸) × 100%` | Окупаемость маркетинговых инвестиций |

## 🚀 Установка и запуск

### 1. Предварительные требования
- Установленный **Node.js** (версия 18 или новее).
- Менеджер пакетов **npm**.

### 2. Клонирование и установка зависимостей
```bash
cd marketing-analytics
npm install
```

### 3. Переменные окружения (опционально для Supabase)
Создайте файл `.env` в корне проекта, если планируете использовать облачное сохранение:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```
*(Приложение полноценно работает и без Supabase — сессия автоматически сохраняется в браузере).*

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу: **http://localhost:5173/**.

### 5. Сборка для продакшна
```bash
npm run build
```
Готовая оптимизированная сборка будет помещена в директорию `dist/`.
